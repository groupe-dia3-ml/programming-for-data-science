# Presentation Slides Guidelines — Final Project

Deliverable file name: `Laurent_slides.pdf` (or `familyNameLeader_slides.pdf`)

## ⏱️ Constraints & Timing
* **Duration:** Strictly **5 minutes** per group.
* **Format:** PDF format.
* **Demonstration:** Live demo using `Laurent_notebook.ipynb` and `dashboard.py`.
* **Q&A:** Questions from the instructor and peers.

## 📑 Recommended Slide Structure (5-6 slides max)
1. **Slide 1: Title & Team** — Project title, dataset name, team members, ESILV Master DS.
2. **Slide 2: Dataset & Problem Context** — The multidimensional domain (Temporal, Spatial, Analytical) and key motivation.
3. **Slide 3: Data Exploration & Preprocessing** — Volume, missing data treatments, feature transformations.
4. **Slide 4: Key Insights & The 4 Indicators** — Summary of results from the 4 queries (Aggregation, Pattern Mining, Time Series, Spatial Clustering).
5. **Slide 5: Interactive Dashboard Prototype** — Architecture and user value of the Dash web interface.
6. **Slide 6: Conclusion, Limitations & Business Value** — What decisions does this prototype enable?
